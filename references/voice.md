# 自然表达与作者声音

## 先诊断，再修改

先确定哪里让读者费力：抽象词过多、主体不明、推理断层、重复铺垫、语气失真，还是整篇节奏雷同。修改问题片段即可，不为展示工作量把每个句子都换一遍。

保留作者的真实评价、幽默、犹疑、直率和用词习惯。正式文字可以克制，个人文字可以有锋芒；不要把所有作者和人物都改成情绪稳定、措辞周全的同一个声音。

## 常见模式与处理

| 现象 | 应检查什么 | 修改方向 |
| --- | --- | --- |
| “标志着重大转变”“彰显深远意义” | 是否有证据支持这种意义 | 写清发生了什么及实际影响 |
| 宣传形容词、无缝强大等赞语 | 是否能落实到功能、条件或体验 | 用已有事实替代，缺事实就删去夸饰 |
| “专家认为”“研究显示” | 是否有可识别的依据 | 具体归属，或降低到作者判断，不编造来源 |
| 句末不断接“从而体现、促进、确保” | 后半句是推理还是装饰 | 补足真实因果，或删去无依据尾句 |
| 回避“是”“有”，滥用“作为、承载、构建” | 是否让简单关系变复杂 | 恢复具体主语和动词 |
| 反复“不是……而是……” | 是否真有需要纠正的对立 | 直接说实际内容，真实对比可以保留 |
| 固定三项排比、虚假的“从 X 到 Y” | 项目是否真并列、端点是否有意义 | 按事实分组，不为破三改成两项或四项 |
| 同义词轮换 | 是否把同一对象变得难以识别 | 人名、术语、核心概念保持一致 |
| 多层“可能、或许、一定程度上” | 哪一层不确定性有意义 | 去掉重复软化，保留必要的一个限定 |
| “值得注意”“下面让我们”“希望有帮助” | 是正文信息还是聊天残留 | 删除元话语，让内容本身衔接 |
| 套路式总结、乐观展望、金句收尾 | 是否增加实质内容 | 在恰当位置结束，不强行拔高 |

不能凭这些词判定文字由 AI 生成。它们是诊断线索，不是禁词，也不是检测器。

## 节奏、标点与排版

长句承载条件和关系，短句落定重点。避免整篇等长，也不人为把自然长句切成许多戏剧性单行。朗读或默读检查停顿、指代、重音与重复，而不是追求句长配额。

减少无功能的破折号、括注、粗体、表情和标题。根据句间关系选择句号、逗号、冒号等标点；项目已有稳定风格时沿用。中文引号遵循中文排版，不机械套用英文大小写或引号规则。

连接词按真实关系使用。删除“此外”后如果关系更难懂，就保留或写出更准确的衔接；不要把自然表达误解成没有逻辑连接。

## 个性与真实性

第一人称适用于作者已有立场、用户授权的观点写作或虚构人物。不添加“我亲测”“我参加过”“我凌晨三点感到不安”等未经材料支持的经历。

具体细节必须来自材料、获准的研究或明确的创作空间。缺乏细节时不能为了让文字鲜活而补造功能、数字、用户反馈和场景。

必要的日期、来源和不确定性不能以“去 AI 味”为理由删除。不会承诺文字通过 AI 检测，也不以伪装人工写作为质量标准。

## 示例

输入：“这个功能极大地赋能用户，带来革命性的体验。”材料仅说明新增批量导出。

可改：“新功能支持批量导出。”

不可改：“用户每天因此节省两小时。”材料没有提供这个结果。

输入：“我没读完，前半段挺有意思，后面重复太多。不推荐新手。”

轻润色：“我没读完。前半段挺有意思，后面重复太多，不推荐新手。”

不应替作者改成“适合所有希望深入学习的人”，也不把没读完改成完整书评。
