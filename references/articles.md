# 文章组织与写作

## 读者先于模板

确定读者读完后需要理解、判断或完成什么。文章长度取决于这个目标与材料深度，不沿用英文 SEO 字数区间作为中文字数标准。标题承诺应与正文实际提供的内容一致。

开头尽快给出具体问题、场景、结果或判断。解释型文章通常尽早回答问题；叙事文章可以保留必要悬念。不要为吸引注意而发明统计、夸大痛点或假装读者存在某种误解。

每一节承担明确工作，每一段围绕一个主要意思发展。读者需要看见主张、依据、例子与限制之间的关系，而不只是“洞察”“赋能”“方法论”等标签。

## 根据材料选择结构

| 类型 | 可采用的组织方式 | 关键检查 |
| --- | --- | --- |
| 解释与知识文章 | 问题或结论 → 机制 → 例子 → 边界 | 说明怎样发生，不只说很重要 |
| 教程 | 目标与前提 → 操作顺序 → 检查结果 → 常见失败 | 步骤可执行，依赖齐全 |
| 实践案例 | 背景 → 原有困难 → 选择与过程 → 结果 → 限制 | 区分已经实现与未来设想 |
| 观点文章 | 主张 → 证据 → 推理 → 有实质性的反例或异议 | 不为了平衡而添加空洞反方 |
| 比较与清单 | 明确维度 → 逐项比较 → 按场景选择 | 不以列表长度充当信息量 |
| 长文综述 | 问题地图 → 分主题展开 → 联系与分歧 | 控制重复，保留各来源边界 |

这些是候选结构，不是必须补齐的栏目。没有实际“挑战”或后续计划时不凑未来展望。结尾完成文章的工作即可，不必重讲全文或升华时代意义。

使用标题帮助定位，使用列表表达并列或顺序，使用表格比较同一维度。不要每两段就强行插小标题、粗体或列表；也不要在标题数量受限时用大量粗体标题绕过要求。

## 信息价值

检查每部分是否提供读者需要的解释、证据、步骤、具体案例、条件或有依据的新判断。删除重复共识与空泛铺垫，但不为“原创性”编造观点或数据。

信息不足时，可以缩小结论、指出缺口、向用户询问或按授权研究；不能用一段更有气势的话补足证据。引用别人的话时保持原意，实质性改写后不要再冒充逐字引语。

## 搜索与商业文章的条件模块

仅在用户有搜索获客、产品介绍或转化目标时启用这些规则，不让知识笔记和私人文章自动变成广告。

先确认读者意图、产品与问题的关系、已确定的关键词和可用证据。需要竞品或搜索结果分析时，检查已有内容遗漏的具体问题、过时信息和服务不足的读者，而不是只写得更长。

标题、开头和小标题自然表达用户会搜索的问题。可以使用简明摘要、要点列表或结论在前的回答段，但不要关键词堆砌，也不承诺排名、点击率或被 AI 引用的效果。

按实际用途选择表达框架：吸引注意后说明价值并引导行动；呈现问题、影响与解决路径；展示改变前后及实现过程。不要为满足框架夸大恐惧或编造效果。

CTA 只在有真实下一步时出现。产品连接要解释它解决了哪一步问题，不把每篇文章都导向购买。外部统计、专家引语和可核实主张需要恰当归属；不虚构作者资历、客户评价、媒体背书。

## 风格参考

读实际样本，提取叙述人称、正式程度、段落长度、信息密度、节奏、论证顺序与幽默方式。保留主题自身需要的专业性，不套用样本中的身份、经历、立场或反复出现的标志句。
