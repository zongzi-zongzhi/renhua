# 人话 · renhua

理解需求，整理知识，把话写清楚。

`renhua` 是一个独立的中文整理与写作 skill。根据任务选择保真、结构、表达、叙事和核查模块，不需要每次执行整套流程，也不依赖其他 skill。

## 能做什么

- 整理零散资料、知识笔记与录音转写，保留必要细节及观点归属。
- 根据材料写文章、教程、案例或观点文。
- 压缩摘要，保留核心结论与必要条件。
- 局部改写、自然润色，保持作者声音。
- 诊断叙事、人物对话与阅读节奏。
- 核对事实、遗漏、结构及交付要求。

“人话”不意味着一律口语化。专业文字保持严谨，个人文字保留个性；不为自然表达添加未经依据的事实和经历。

## 安装

将仓库下载或克隆到本地，把包含 `SKILL.md`、`agents`、`references` 的整个目录命名为 `renhua`，放入 Codex 的 skills 目录：

```text
~/.codex/skills/renhua/
```

如果使用了自定义 `CODEX_HOME`，则放入该目录下的 `skills/renhua/`。目录已存在时，先检查已有内容，避免覆盖自己的修改。

## 使用

```text
用 $renhua 整理这份材料，保留细节，写得自然一些。
```

```text
用 $renhua 润色这篇文章，只调整表达，不改变我的观点。
```

```text
用 $renhua 把这份报告压成三百字，保留关键结论和限制。
```

支持自动匹配相关任务，也可以显式指定 `$renhua`。篇幅、口吻、标题数量和保存位置由当次任务决定。

## 文件结构

```text
SKILL.md                  统一入口与任务选择
agents/openai.yaml        显示信息和调用设置
references/materials.md   材料理解、知识整理与保真
references/articles.md    文章组织与写作
references/voice.md       自然表达与作者声音
references/narrative.md   叙事与阅读体验
references/review.md      核查与交付
```

入口只加载相关模块。简单润色不会强制扩写，摘要不承诺保留全部细节，纪实整理不借用虚构写作补造场景。
